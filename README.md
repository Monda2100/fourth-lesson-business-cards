# 第五堂課｜建築師考古題

本課程資料夾已整理考選部 113、114 年建築師考試官方考古題與答案，並附上「建築師考古題模擬測試 APP」。

## 使用 APP

直接開啟 [app/index.html](app/index.html)，即可開始測驗。APP 內建 461 題測驗式題庫，可依年度、科目、題數與作答模式抽題；測驗完成後會顯示正確率、標準答案與本機作答紀錄。

## 資料夾內容

- `建築師考古題/`：113、114 年六科官方 PDF。測驗科目另附答案 PDF；敷地計畫與都市設計、建築計畫與設計為官方試題原卷。
- `data/questions.json`：由官方試題與答案 PDF 萃取的題庫資料。
- `data/questions.js`：供 APP 直接離線開啟使用的題庫載入檔。
- `scripts/`：題庫萃取與 APP 題庫檔產生工具。

## 官方來源

- [113 年考畢試題查詢平台](https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx?e=113190&y=2024)
- [114 年考畢試題查詢平台](https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx?e=114180&y=2025)

資料來源為考選部，APP 僅作為課程練習工具；原始 PDF 已保留在 `建築師考古題/` 中供核對。
